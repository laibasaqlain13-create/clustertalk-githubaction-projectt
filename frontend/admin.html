⚙️ How the Load Balancer works

Loading mesh...
UPDOWNRECOVERINGUNKNOWN
  • 1Round-robin: new clients are spread evenly across all healthy servers, so no single one overloads.
  • 2Sticky: each client stays pinned to its own server, so its session & history stay in one place.
  • 3Failover: if a server goes DOWN, its clients are moved to the healthy ones — nobody is dropped.
  • 4Failback: when that server comes back, its own clients return to it automatically.
  • 5Auto-scale: nodes register / deregister live and are health-checked every few seconds — the pool adjusts instantly.
